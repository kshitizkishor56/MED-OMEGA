# Install on iPhone

1. Deploy to HTTPS and open the URL in Safari on iPhone.
2. Load the page fully once online and let caching finish.
3. Tap Share → Add to Home Screen → Add.
4. Launch MED-OMEGA from its Home Screen icon. Test offline after the first load.

Import screenshots using the iOS image/file picker. To use ChatGPT, copy the prompt, open ChatGPT, attach the image yourself, then paste its response back into the screenshot workflow. No link transfers images or retrieves answers automatically. iOS can evict site storage; export backups regularly.
